[tPlainModLoader](https://github.com/github-user-64/tPlainModLoader)的模组

> 这里的模组都不能重新加载，不然一些功能会用不了

## 组模:起床战争
* 在单人和客户端时是编辑地图模组，启用编辑按钮在进入游戏后物品栏右侧。
* 发布的模组自带起床地图了，起床的地图会覆盖原有的图格，建议用没用的地图开服。
* 在控制台输入`起床重置`回到初始化状态。
### 📌编辑建议
商店价格就用默认的应该就好了，生成物品别太快或太多除非你服务器比较流畅（自己做的图全踩雷了，或许你可以在自带的图基础上改

## 模组:账号和权限
注册:`/register 四位数密码`

登录:`/login 注册的密码`

玩家账号的`管理等级`标签值越小代表等级越大，0为服主级别
